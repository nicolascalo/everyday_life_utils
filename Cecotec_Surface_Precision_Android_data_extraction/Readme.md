# Script to extract measurment from the Cecotec Surface Precision Android app

## Background

The Cecotec Surface Precision 10600 balance uses the Surface Precision app to record body weight and composition measurements of its users.

https://www.storececotec.fr/fr/pese-personnes/soin-du-corps-pese-personne-surface-precision-10600-smart-healthy-pro-beige
https://play.google.com/store/apps/details?id=com.cecotec.surfaceprecision&hl=en

However, since an update of Google fit's communication protocols with fitness apps, there is no way to export the measurements to another device. This is especially cumbersome as the Surface Precision app is not able to adequately display line charts for body weight/composition over a selected period of time.

This script allows to extract the measurements from the app "screenshots" after conversion to pdf, to aggregate them, store them in .csv files according to the user name, and to graph the measurements over time.

## Requirements (Windows device)

- Python 64-bit 3.13
- OCRmyPDF:
  https://github.com/ocrmypdf/OCRmyPDF
- Tesseract 64-bit & Ghostscript 64-bit: https://ocrmypdf.readthedocs.io/en/latest/installation.html#native-windows

- Individual measurement files (.jpg) generated by the "share" function of the Surface Precision Android app (not tested on iOS but should work if the output is the same)

## Instructions

- Add the .jpg files in the "./data_to_process_jpg" folder
- Run the Cecotec_Surface_Precision_Android_data_extraction.py script
- Retrieve the processed data in the "./processed_data" folder

## Notes

- The script will update already existing .csv files with the newly processed data and overwrite any existing graphs
- The folder "./data_conv_to_pdf" is used to hold temporary .pdf files used for data extraction
- Original .jpg and produced .pdf files will be renamed in the user_YYYY-MM-DD_HH_MM format in a newly "./processed_data/user/raw_data_renamed" folder
- An already processed dataset is provided as an exemple of the script imput and output
